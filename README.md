# opened-arm

> Public operational handoff and reproducible utilities for the opened ARM work.

This repository's existing project content remains on `main`.

## Isolated VELA experiment branch

The branch `vela-experiment-infra` is an isolated workspace for Ars Mentis / VELA experiment infrastructure. It must not be merged into `main` unless explicitly requested.

VELA experiment files live under:
- `experiments/vela-active-state/`
- `.github/workflows/vela-*.yml`
- `ops/vela-results/`

Other project areas are out of scope for VELA experiment writes.
